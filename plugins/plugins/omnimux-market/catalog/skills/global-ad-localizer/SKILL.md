# 出海多语言视频广告本地化（Global Ad Localizer）

本技能面向 TikTok、Amazon、Instagram Reels、YouTube Shorts 与跨境独立站场景，将经过验证的商品广告素材或分镜创意，系统化扩展为覆盖多国家、多语言、多受众与多平台画幅的本地化视频广告矩阵，同时通过 OmniMux 商品库、资产库与多模态工作流锁定商品外观与事实边界。

## 核心工作原则

1. **四栏本地化拆解矩阵**
   - **全球锁定项（不可篡改）**：商品实拍外观、材质工艺、包装比例、品牌主色、Logo 规范、经核实的数字参数与合规卖点。
   - **目标市场适配项（语境重塑）**：出镜人设与表达方式、居家/户外使用场景、季节光线、消费习惯与开场 3 秒视觉钩子。
   - **本地待审项（人工把关）**：母语口播文案、促销与税费表述、功效声明及目标平台广告合规准入（严禁凭空编造认证或疗效）。
   - **禁止项（合规红线）**：刻板印象、未授权地标/品牌商标、敏感宗教或政治符号、未经核实的对比夸大承诺。
2. **平台画幅与安全区规范**
   - **TikTok / Reels / Shorts**：9:16 竖屏，避开右侧交互区与底部字幕区；前 2–3 秒建立冲突或场景反差。
   - **Amazon / 独立站商详**：16:9 或 1:1，优先清晰呈现商品结构、真实使用演示与核心卖点特写。
3. **先提案、先小样、再扩量**
   - 在调用任何付费生图/生视频工具前，先向用户交付四栏拆解矩阵与目标市场分镜提案；
   - 默认先在 1 个目标市场产出 1 条核心小样镜头验证外观锁定与风格一致性，获用户明确确认后再扩展至多市场批量清单；
   - 文字字幕、价格、促销标签与免责声明统一交由后期剪辑叠层处理，不在视频生成提示词中烧录复杂小字。

## 标准执行流程

1. **锁定商品与素材真源**：
   - 收集用户提供的商品参考图、源视频链接、目标国家/语言与分发渠道；
   - 如商品已入库，优先经 OmniMux 商品库与资产库工具（如 `products_list` / `products_get` / `products_read_media`、`assets_list`）读取已核实参数与实拍图，缺关键事实时先澄清再动工。
2. **输出四栏本地化提案**：
   - 逐市场列出「元素 / 原版 / 本地化方案 / 调整理由 / 风险提示」对照表；
   - 明确标注商品主体锁定参考图、场景/人物变更说明与后期字幕安全区位置。
3. **单市场小样验证与批量生成**：
   - 仅在用户确认提案后，使用会话内实际可用的 OmniMux 图像/视频生成工具（如 `omnimux_image_submit`、`omnimux_video_submit`）或创作画布工作流（`workflow_*`）执行单条小样生成；
   - 经用户审查小样外观一致性与文化适配无误后，再按确认清单逐项展开剩余市场版本，必要时交付至剪辑工坊（`clip_*`）完成配音、母语字幕与成片导出。
4. **交付台账与复核清单**：
   - 输出「市场 — 语言 — 平台画幅 — 锁定参考 — 产物路径/状态」台账，并显式列出仍需本地母语与法务团队复核的待办项。
