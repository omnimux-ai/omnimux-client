# 短视频五维拆解与前 3 秒 Hook 诊断（Video Breakdown & Hook Analysis）

本技能用于拆解 TikTok、Instagram Reels、YouTube Shorts 或本地参考短视频的传播逻辑、黄金前 3 秒钩子（Hook）、叙事节奏、镜头语言与可迁移复刻结构。分析全程遵循**事实四级分类**（工具实测观察 / 用户提供输入 / 显式标注假设 / 未知项），严禁在未看到视频画面时编造镜头或台词，也不做保证爆款或转化率承诺。

## 适用场景

- 用户发送一条本地视频、灵感库条目（`@inspiration/...`）、资产视频（`@asset/...`）或公开社媒视频链接，要求「拆解这个视频」「分析开头钩子」「提炼分镜和脚本模板」。
- 在复刻爆款或制作带货视频前，需要先剥离原片的「灵魂（可复用结构与节奏）」与「外壳（原产品、人设与品牌词）」。

## 工具真源与输入准备

按输入形态选择当前会话已注册的真实工具，不得虚构工具名或跳过取证：

1. **本地视频或工作区虚拟引用（`.mp4` / `.mov` / `.webm` / `@inspiration/...` / `@asset/...`）**：
   - 如需核对时长、画幅或体积，可先用 `video_process`（`capability: "media_metadata"`）；若原视频过大无法直接进多模态理解，再用 `video_process`（`capability: "video_inline_analysis_prepare"`）在保留完整时间轴的前提下压至可分析体积。
   - 如需精确核对原声口播文本，可配合 `video_process`（`capability: "audio_extract"`）与 `omnimux_speech_to_text` 提取转写。
   - 调用 `video_analyze` 执行原生视频五维度深度拆解（传入绝对路径或 `@inspiration/...` / `@asset/...`，需要落盘时传绝对路径 `dest`）。
2. **灵感库已有条目**：
   - 先调用 `inspiration_get` 或 `inspiration_search` 读取已有元数据、本地媒体路径与历史拆解结果，避免重复下载。
3. **公开社媒视频链接（TikTok / YouTube / Instagram）**：
   - 优先按平台调用 `omnimux_tiktok_video`、`omnimux_youtube_video`、`omnimux_instagram_post` 或 `omnimux_social_data` 获取公开元数据、文案、互动指标与可用视频地址。
   - 若工具仅返回文字与指标而未提供可分析的本地视频文件，**如实告知缺口**：明确说明当前仅完成文案/数据层拆解，提示用户上传视频文件或存入灵感库后再做逐镜头画面分析，严禁脑补未看到的画面细节。

## 五维度标准输出结构（对齐 `video_analyze` 真源契约）

收到 `video_analyze` 原始输出后，校验并整理为结构清晰、可直接交给下游脚本/画布消费的中文专业报告（保留关键英文术语，如已有明确输出要求则以用户要求为准）：

### 0. 一句话视频概述
- 用 ≤60 字概括视频核心题材、叙事载体与核心卖点或冲突。

### 1. 前 3 秒黄金 Hook 专项诊断（0–3s）
用紧凑表格呈现开头留存机制，每一项都标注**直接观察到的证据**：
| 维度 | 观察到的具体表现（画面/字幕/声音） | 触发的心理机制 | 可迁移改写要点 |
| --- | --- | --- | --- |
| 视觉钩子（Visual Hook） | 景别、动作反差、构图焦点、道具出现时机 | 好奇/反差/痛点直击 | 保留动作节拍，替换成我方产品核心画面 |
| 语言/花字钩子（Verbal & Text Hook） | 首句台词或屏幕大字（仅写实测听见/看见的原文） | 身份点名/利益承诺/认知冲突 | 替换为已核实的产品痛点句式 |
| 节奏切点（Pacing Cut） | 前 3 秒切镜次数与首切秒数 | 维持注意力密度 | 复用同等切镜密度 |

### 2. 核心目标与影响力分析
- **核心目标**：转化带货 / 种草心智 / 互动涨粉 / 线索留资，以及情绪基调与风格证据。
- **明线卖点（Explicit）**：画面与台词明确展示的功能、场景、对比演示。
- **暗线价值（Implicit）**：身份认同、情绪共鸣、生活方式暗示或痛点焦虑缓解。

### 3. 叙事结构与人声/表演拆解
- **叙事载体与人物原型**：口播真人 / 剧情短剧 / 纯视觉演示 / 街采对比；人物身份感、表演状态与语气语速。
- **三段式信息序列**：`[0–3s Hook] → [中段证明/演示/反转] → [结尾 CTA]`，指出每一拍承担的说服任务。

### 4. 画面语言与逐镜头拆解表
给出按时间码连续覆盖的镜头表（时间码、景别与运镜、关键动作、画面/提示词要点、可替换脚本变量 `{Product_Name}` / `{Pain_Point}` / `{Target_Audience}`），并区分哪些细节是直接观测、哪些是推断。

### 5. 核心复刻策略（灵魂 vs. 外壳）
- **必须保留的「灵魂」**：Hook 冲突结构、信任证明方式、音画配合节拍。
- **必须替换的「外壳」与合规提醒**：剥离原片品牌标识、水印、第三方未经核实功效宣称与违禁绝对化用语，列明套用到用户自己产品时需要补齐的真实素材与参数。

## 后续衔接

- 如用户希望沉淀本次拆解供后续复用，可经 `inspiration_create` / `inspiration_update` 保存到灵感库，或按用户指定路径经 `video_analyze` 的 `dest` 导出。
- 报告末尾只给 1–2 个贴合下一步的动作建议（例如：进入 `reverse-video-prompt` 反推 I2V 生成提示词，或结合商品库进入 `create-selling-video` / `replicate-viral-video` 编排成片），不喧宾夺主。
