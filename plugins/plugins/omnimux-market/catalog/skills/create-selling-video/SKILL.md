# 一键创作带货短视频（Create Selling Video）

本技能面向跨境电商与内容带货场景，将「商品信息（必填真源）+ 参考视频（可选）」转化为可审查、可迭代的带货短视频。全流程严格复用 OmniMux 现有工作区设施（商品库 `products_*`、资产库 `assets_*`、视频理解 `video_analyze` / `video_reverse_prompt`、创作画布 `workflow_*`、剪辑工坊 `clip_*`），坚持**事实真源优先、先定锚再扩量、付费生成与导出前显式确认**，严禁编造商品参数、虚构功效或承诺爆款销量。

## 执行阶段与标准 SOP

### 阶段 1：锁定商品事实真源（严禁幻觉）
1. 读取用户附带的商品卡片、图片或链接；若商品已存入商品库，调用 `products_list` / `products_search` / `products_get` 与 `products_read_media` 获取已核实的参数、卖点、受众与实拍主图。
2. 如需复用既有模特人设、场景或音色，调用 `assets_list` / `assets_search` 检索已有资产，避免重复生成。
3. 按**四级事实边界**收口卖点：
   - 仅使用工具实测或用户确认的产品外观、尺寸、材质、核心卖点与适用场景；
   - 绝不擅自添加未提供的认证、折扣、价格、医疗/功效保证或夸大对比；
   - 缺少关键商品图或核心卖点时，先用简洁问题向用户确认后再进入制作。

### 阶段 2：可选参考视频拆解
- 若用户同时提供了参考爆款视频或灵感库条目：
  - 先用 `inspiration_get` 查看是否已有拆解，否则用 `video_analyze` 提炼 0–3s 黄金 Hook、叙事节拍与转化结构；
  - 若需要复刻镜头动作节奏做 I2V 生片，可进一步调用 `video_reverse_prompt`（`identity_mode: "A"`，配合 `product_or_prop_swap`）产出可执行的无声表演/运镜提示词；
  - 彻底剥离原片第三方品牌标识、水印与非本品宣称。

### 阶段 3：输出带货导演提案并确认（付费生片前闸门）
在触发画布付费生图/生视频前，先向用户呈现精简可拍板的制作方案：
- **基础规格**：目标平台（默认 TikTok 9:16 竖屏）、目标时长（如 15–30s）、目标语种与口播/纯画面策略。
- **核心卖点与 Hook**：前 3 秒开场画面与钩子句式（聚焦 1 个核心痛点/卖点，不堆砌）。
- **逐镜头分镜表**：镜头序号、时长、景别运镜、画面表现（明确是否需商品参考图锁定外观）、口播/字幕文案与音效设计。
- **锚点先行策略**：默认先确认首帧/关键商品图锚点与单条样片方向，再决定是否批量生成多镜头或多语言变体。

### 阶段 4：创作画布编排与生成（`workflow_*`）
用户确认方案或明确授权直接生成后，在创作画布落地完整 DAG：
1. 调用 `workflow_list` 查看当前工作区画布；无现成画布时调用 `workflow_create` 创建命名清晰的新画布（如「<商品名> 带货短视频」），避免重复新建孤立画布。
2. 用 `workflow_node_add` 与 `workflow_connect` 编排标准拓扑：
   - 商品参考图/素材导入节点（`material_type: "image"`, `tool: "import"`）
   - 分镜关键帧生图节点（`material_type: "image"`, `tool: "image-to-image"` 或 `"text-to-image"`，用连线绑定商品锚点图以锁定商品外观）
   - 分镜视频生成节点（`material_type: "video"`, `tool: "video-generation"`，连线接入关键帧与提示词）
   - 如需配音或配乐，可先查 `omnimux_audio_voices` 选定音色，再编排 `material_type: "audio"` 节点
3. **线路与引用数校验**：修改视频生成参数前必须先调用 `workflow_snapshot`（含 `include_nodes: true` 或指定 `node_id`）读取真实可用模型与渠道分组，通过 `workflow_node_update` 写入合法参数；若参考图数量超出所选模型上限，向用户说明限制并由用户决定裁剪或换模型，绝不静默丢图或擅自换线。
4. 调用 `workflow_run` 执行画布（必要时通过 `workflow_execution_control` 暂停或取消），完成后核查生成文件的完整性、画幅比例与商品外观是否严重畸变；不做主观审美死循环重绘，如实呈现客观结果交由用户定夺。

### 阶段 5：Clip 多轨装配、体检与受控导出（`clip_*`）
当存在多段镜头、配音、字幕或背景音乐时，在同一步完成剪辑工程装配：
1. 调用 `clip_list` / `clip_create`（或复用当前工程 `clip_get`），通过 `clip_edit` 装配画面轨、配音轨、BGM 轨与字幕花字，并用 `clip_open` 在剪辑工作台打开供用户直观审查。
2. 每次时间轴编辑后必须运行 `clip_diagnostics`，修复断帧黑场、轨道重叠或缺失媒体等客观问题。
3. **成片导出确认**：先交付可编辑 Clip 工程供用户微调；仅当用户明确要求导出成片或批准当前剪辑后，才调用 `clip_export`（传 `confirm: true`）渲染最终 MP4。

## 交付汇报要求

严格区分「工具执行成功」「可编辑工程已就绪」「成片已导出」三种状态：汇总已生成的画布/Clip 工程名称、产出素材数量、执行的 `clip_diagnostics` 结果以及待用户确认或补拍的项，不把脚本或未渲染草稿表述为已成片。
