# Cross-Border E-commerce Platform Rules & Compliance Guard

## Overview
本技能是 OmniMux 跨境电商 SOP 专家体系的共享规则与合规底座。所有选品、定价、Listing 文案、主图视觉、短视频脚本、广告诊断与评论售后环节均须遵循本规则卡，防止跨平台规则混淆、参数虚标与账号合规风险。

## When to Use
- 需要核对 Shopee / Amazon / TikTok Shop / Mercado Livre 任一平台的标题、主图、视频或类目规范；
- 需要进行文案/脚本/视觉的合规守卫检查（绝对化用语、未授权品牌、医疗功效宣称、灰产拦截）；
- 需要在 SOP 上下游之间对齐单一参数真源（`spec_table`）、唯一核心卖点（`core_selling_point`）与禁用词清单（`forbidden_words`）。

## Platform Rules Reference

| 维度 | Shopee (BR/SEA) | Amazon (US/EU) | TikTok Shop (US/UK/SEA) | Mercado Livre (BR/MX) |
|---|---|---|---|---|
| 标题上限 | 120 字符 | 200 字符（推荐 ≤150） | 255 字符（推荐 40–120） | 60 字符（严控精简） |
| 首图规范 | 1:1，≥800×800px，主体突出 | 1:1，≥1000×1000px，纯白底 RGB≥245，主体占 65%–90%，无文字水印 | ≥600×600px（推荐 1200×1200），清晰无杂乱边框 | ≥1200×1200px，纯白底，无文字/Logo/水印 |
| 标题禁区 | 促销词、全大写、堆砌无关热词 | 促销价/限时词、主观最高级、他人商标 | 夸大疗效、引导站外交易、违禁词 | 运费/折扣/促销词、联系方式、符号堆砌 |
| 典型视频规格 | 15–60s，1:1 或 9:16 | 15–60s，16:9 或 9:16 | 15–45s，9:16 竖屏，前 3 秒强 Hook | 15–45s，9:16 优先 |
| 常见费率项 | 基础佣金 + 免运/返现活动费 + 支付手续费 | 类目佣金（常见 8%–15%）+ FBA 配送与仓储费 | 类目佣金 + 达人联盟佣金 + 平台运费补贴 | 经典/高级刊登费 + 固定件费 + 运费分担 |

## Cross-Stage Truth Contract（跨环节防漂移契约）
1. **唯一核心卖点（`core_selling_point`）**：产品定位阶段必须收敛为 1 个主卖点；未确认主卖点前，下游主图与视频脚本不直接批量开工。
2. **单一参数真源（`spec_table`）**：尺寸、重量、容量、材质、续航、件数、功率、适配型号等数字参数统一写入 OmniMux 商品库（`products_*`）或 `spec_table` JSON，下游文案、主图与短视频中的所有数字必须可回溯到真源。
3. **四级事实分类**：
   - **已核实事实**：导出表数据、工具实测结果、商品库已确认参数；
   - **用户确认输入**：用户明确提供的成本、库存、实拍图与规则偏好；
   - **显式假设**：推算用默认值（必须醒目标注「假设」）；
   - **未知项**：缺失信息（必须留空或向用户确认，严禁脑补）。

## Compliance Guard（硬性合规红线）
以下内容在任何输出中均 **严禁出现**，命中即拦截并改写：
- **绝对化与虚假保证**：`100%`、`#1`、`最好/第一/顶级/永久/根治`、`best in the world`、`guaranteed viral`、`garantido 100%`、`milagroso`、`保证爆款`、`保证出单`、`防封号`。
- **医疗与未证实功效**：未经认证的治病、抗菌、防癌、减脂、医用级宣称；未获证书的 CE / FDA / ANATEL / INMETRO 认证徽章。
- **知识产权红线**：未经授权的第三方品牌名、联名词、受版权保护角色名或竞品专属专利号。
- **平台灰产红线**：刷单、测评返现、诱导修改/删除差评、虚假原价划价、站外导流绕开平台交易。
- **后台操作红线**：不代操作卖家中心上架、不代修改广告出价/预算、不绕过授权自动发布；涉及此类操作仅输出分级审批清单由人工确认执行。

## Output Format
调用本规则卡辅助评审时，输出简洁的「平台规则对账 + 合规拦截清单（通过项 / 阻断项 / 改写建议）」，不堆砌空泛套话。
