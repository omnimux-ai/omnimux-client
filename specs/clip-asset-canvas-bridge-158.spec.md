# 剪辑素材库与创作画布桥接（#158）

验收口径以 [#158 的交互裁决](https://github.com/omnimux-ai/omnimux-client/issues/158#issuecomment-7076371788) 为准。用户可从剪辑素材库直接选取已有媒体，也能暂离当前剪辑工程，在现有画布取得素材后继续编辑。

## 假设

- Studio 和画布 Portal 挂载同一媒体面板。使用一个三项导入菜单、两个桌面快捷入口和同组空态入口，能在保留系统文件选择及录制的前提下覆盖两种剪辑入口。媒体面板宽度小于 240px 时由菜单承担导入操作。
- 资产库已经提供素材身份及同源文件预览。剪辑器可由这些只读引用复用现有的媒体解析、素材池和草稿持久化。同一个库文件在同一个工程内只入池一次，解码失败可单项重试。
- 剪辑会话已经串行协调原生编辑器归属、IndexedDB 写入与 Host 草稿提交。画布跳转复用这个提交边界。画布工作区和连接由 Workflow 持有，独立工坊优先去本会话已开的画布页，其次使用本工作区已有的最近页。画布 Portal 保留工作区、节点、工程三元组。
- 交互以既有真机运行入口和设计系统为参照。开发对照从当前主线的实际媒体面板和已批准演示取样，候选使用相同入口。工作区切换或持久化请求失败时，受影响的动作应在原工作面可恢复。

## 实现边界

- 导入确认锁住本次选择，素材池呈现进度、成功卡片与失败重试。空时间轴导入一批媒体时，首个视频采用自身画幅并放在时间轴起点。已有时间轴内容不改尺寸或自动入轨。
- 跳转前确认当前草稿已写入本地且与 Host 同步。独立工坊通过画布顶条勾选已生成媒体，回到同会话的原剪辑工程并读最新稿。取消返回原工程。画布 Portal 退出至所绑定节点，新的上游连接或版本在明确返回时进入原素材池。
- 生成节点按当前执行状态列出已完成素材，旧图没有执行状态时沿用历史完成标记。普通 Portal 打开和回流使用同一文件版本。已有素材按来源和已验证的内容摘要复用，保留原素材 ID。
- 回流状态限于当前渲染器及绑定的会话、目标工作区和原工程。读取失败的回流素材在媒体面板显示单项重试，重开原节点时也会继续处理尚未导入的项。读媒体使用现有同源接口。插件工具契约、桌面壳、画布下游布局和生成执行路径保持原有入口。

## 证伪方式

| 验收 | 同一测试的操作和判定 |
| --- | --- |
| AC-158-01 | 从 Studio 和画布 Portal 的媒体页打开选择器，搜索及筛选图片、视频、音频，跨筛选多选并导入。核对各项真实媒体内容、首个视频尺寸与起点，回读已保存工程。 |
| AC-158-02 | 选择多项后连点导入，扣住其中一条文件响应并让它失败。核对同一文件只有一次初次读取，已入池卡禁止重复选择，失败项只重试自己。切走席位后释放旧响应，另一个工程的素材池和时间轴保持原样。 |
| AC-158-03 | 编辑未保存文字后点去画布，把 Host 保存响应延后，再核对跳转先后。画布 Portal 连入新素材并返回同节点，断线后重连同一文件时核对原素材 ID。让回流读取先返回 503，再验证单项重试和重开节点各自恢复。独立工坊列出执行完成和历史完成的节点，排除重跑中的旧输出，选择素材回到原稿，再走一次取消。核对原工作区、项目列表、文字和素材，以及已保存草稿内的回流结果。 |
| AC-158-04 | 复核中英、亮暗、宽于和窄于 240px 的媒体面板。菜单、选择器和画布回流条可用键盘和鼠标操作，浮层背景实色。验证实际只读接口、桌面壳及并发文件无差异，以及模拟素材运行的模型请求为零。 |
