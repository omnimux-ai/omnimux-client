# 移除渠道选择中的「官方专线」分组标题

## 背景

画布素材节点的模型级联菜单（`ModelCascadeMenu` → `CascadeChannelColumn`）在「渠道」标题下，会为官方渠道单独渲染一个「官方专线」分组小标题。用户要求移除这个文本元素；该列由 `MaterialNode` 的 `ConfigPanel` 共用，因此图片、视频、音频、文本节点都会覆盖。

## 目标

- 删除 `CascadeChannelColumn` 中「官方专线」分组标题的渲染。
- 「渠道」列标题、官方渠道卡片、BYOK「自备渠道」分组及其空态保持不动。
- 不改变 channelGroups 数据来源、价格、选中与路由逻辑。

## 非目标

- 不删除渠道分组数据，不修改网关 `usable_group` 或本地 `channelGroups`。
- 不删除「自备渠道」标题。
- 不改任何渠道选择行为或提交参数。

## 验收

1. 任意素材节点（图片 / 视频 / 音频 / 文本）打开模型级联菜单的渠道列：只有「渠道」标题，下方直接是渠道卡片，没有「官方专线」小标题。
2. 存在自备渠道时，「自备渠道」分组和分隔线仍在。
3. `modelCascadeMenu.test.mjs` 增加静态断言：组件源码不再出现「官方专线」文本；现有渠道选择、路由和模型切换断言保持通过。
4. 受影响构建通过。

## 旧标准变更

无。本次只新增断言，不削弱既有测试标准。
