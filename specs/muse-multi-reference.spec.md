# Muse 多图参考上限对齐

OmniMux 的首发契约公开了固定两张参考图。当前 Muse2API 接入版本接受最多十个参考素材，视频接口保留图片数组顺序。本次把纯图片参考扩到 2–10 张，沿用第一张为起始图和独立的单图首帧模式。[首发契约](https://github.com/omnimux-ai/omnimux-gateway/pull/54) · [接入上限](https://github.com/laozhong86/muse2api/blob/1e8bf23119e4de271bf655f2afaac56b73826cb2/engine.py#L44)

画布沿用首发版的缩略图、交换和素材选择器。扩展后复用现有素材卡片的换行布局，起始图有明确标识，可从参考图操作中将其与起始图交换。张数、格式和首图用途以网关契约为依据。对仍开启固定两张的网关，界面继续展示双图参考及对应上限。

## 验收

- 已保存的首帧和双图节点重开后保持模式、有效图片和首图顺序。旧版和新版绑定均能从选择器追加图片与按位替换。
- 在扩展契约下，从第 2 张补到第 10 张，保持选图顺序和原连线。第 11 张不能挤掉已选图片。少于 2 张时生成不可用。
- 将任意参考图设为起始图，保留其他位置。保存在项目里的有效顺序与 Agent 工具、画布和执行请求一致。
- 从隔离画布入口验证亮暗主题、窄屏和展开的选图操作。用合成素材验证 1、2、3、10、11 张边界及完整转发次序，沿用测试环境进行真实视频验收的授权边界。
