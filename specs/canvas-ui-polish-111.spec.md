# 规格：创作画布视觉与交互优化（Issue #111）

## 1. 背景与目标

针对 `omnimux-workflow` 创作页通用 MaterialNode（文本、图片、视频、音频）及画布操作栏的三类高频交互摩擦，在不改变业务模型能力、节点类型与 `#88` 素材分配语义的前提下，交付三项纯 UI 视觉与交互优化：

1. **P1 · 底部工具直点与键盘可达**：原位清晰呈现「添加节点」入口；将「选择」「抓手」拆为并列两颗直点按钮（1 次点击直接互切、`aria-pressed` 互斥），保留 `V` / `H` 快捷键及高对比 `:focus-visible` 焦点环；视口控制保持右上角分组且分隔清晰。
2. **P2 · 节点标题对比度与三态交互反馈**：浅/暗双主题下节点标题与参数菜单相对实际背景均达到 WCAG AA ≥ 4.5:1；清晰区分悬停（卡外中性细边，移开即退）、单选（卡外实线轮廓，移开留存，点空白取消）、按住拖拽（独立虚线轮廓与投影，松手即退）三态；完整保留节点几何、预览、角标、操作与左右连接把手。
3. **P3 · 配置面板按实际内容高度动态避让与底部停靠**：空间充足时贴合节点下方；首次打开或同一次选中内参数/卡槽变化导致内容高度改变时，实时按实际内容高度测算与相邻节点卡片/标题、画布边界及悬浮工具栏（含单节点 `1024×720` 下与 `.wf-canvas-toolbar` 的重叠）的碰撞；发生碰撞时自动平滑移入画布底部预留停靠区（必要时参考图槽与提示词并排紧凑布局，长内容面板内滚动），空间恢复时自动回归贴卡与完整画布高度；避让后相邻卡片标题与上沿零遮挡、无需关面板单点即可直接选中相邻节点；保留已输入提示词、视口倍率与相机位置；连续抓手平移/拖拽手势期间锁定当前布局模式，松手停在终点无额外位移。

## 2. 方案选型与约束

- **设计系统单一真源**：全部颜色、描边、焦点环与表面均消费宿主 `--dsw-alias-*` / `--wb-*` 语义 Token，严禁写死调色板字面量或新增透明/伪毛玻璃浮层。
- **Show, Don't Tell**：不因工具切换、节点三态或贴卡/停靠切换新增冗余 Toast、Banner 或内联提示条，不为测试断言塞 UI 文案。
- **与 `#88` 具名卡槽完全兼容**：`ConfigPanelShell` 通过 Portal 挂载于 `.wf-canvas-editor` 内（与 ReactFlow 同属 `.wf-canvas-root`，自动继承双主题语义变量），无 `.wf-canvas-editor` 容器的隔离单测环境回退到内联渲染。停靠紧凑态仅在 `data-preset="strip"` 且槽位 ≤ 2 时并排；`pair`、`named` 及多槽超长内容保持完整流式换行与面板内滚动。面板位置变化时派发 `omnimux:config-panel-position`，参数浮层（`CfgPopoverShell`、`ModelCascadeMenu`、`CustomSelect`）同步更新定位。
- **单次手势稳定**：在画布指针按下或滚轮手势期间锁定当前 `anchor / dock` 模式；若用户手动平移或拖拽了画布，松手后不再触发自动校正平移，确保相机精准停留在手势终点。

## 3. 验收矩阵

在 `1024×720` 与 `1440×900`（`DPR=1`、缩放 `100%`）× 浅色 / 深色共 4 组环境下通过真实打包 Web Host + Chromium 交互验收，覆盖：

1. P1 工具直点、键盘 `Tab`/`Enter` 焦点环、`V`/`H` 快捷键、添加节点菜单与空画布新建/入图、小地图可见可交互；
2. P2 节点标题及参数菜单文字相对实际背景对比度 ≥ 4.5:1、悬停/单选/按住拖拽三态截图与运行态区分、左右连接把手与节点操作可用；
3. P3 拥挤图自动停靠与单点选中相邻节点、疏排图同一次选中内「文生图」切「参考图」动态停靠（零遮挡、点击标题与上沿下 14px 直选尾帧）、切回恢复贴卡、单节点 `1024×720` 避让 `.wf-canvas-toolbar`、提示词/倍率/相机保持与连续平移手势稳态；
4. `#88` 具名卡槽添加/替换在贴卡与停靠双模式下正常工作；
5. 回归变异双向证伪与全量静态门禁、单测、`build:all` 及远端 CI 必需检查全绿。
