# 画布状态栏显示重试结果

## 问题

H3 已受理任务第一次因成片地址晚到而显示失败。用户重试后，画布节点和执行队列已显示完成，状态栏仍显示旧失败。

## 依据与决定

在同一画布里观察到两条执行记录。现有状态栏把全部历史一起汇总，并让失败优先于成功。GitHub Actions 的运行页默认展示最新尝试，并提供入口查看之前的尝试。[查看以前的运行尝试](https://docs.github.com/en/actions/how-tos/manage-workflow-runs/re-run-workflows-and-jobs#reviewing-previous-workflow-runs)

画布仍优先展示进行中的执行。都结束时，状态栏展示最近操作的终态和进度；较早发起的执行迟到结束时，不覆盖最近操作。执行队列保留各次结果和错误原因。

## 验收

- 在隔离桌面的同一个 H3 节点发起生成。模拟网关受理后暂不返回成片，右上角显示「执行失败」。
- 点击「重新生成」，从原任务取回成片。右上角显示「已完成」，成片可播放，模拟网关只收到一次生成提交。
- 打开执行队列，最近的执行显示「已完成」，第一次执行仍显示「执行失败」和原错误。
- 并行执行仍以进行中的任务为准。最近一次提交失败或取消时，状态栏能显示对应结果。
- 重新打开画布时，较早的执行恢复信息不能覆盖已经跟踪的提交或改变最新操作的顺序。
