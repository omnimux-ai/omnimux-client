# #63 自动素材断线补位

[#63](https://github.com/omnimux-ai/omnimux-client/issues/63) 与 [#88](https://github.com/omnimux-ai/omnimux-client/issues/88) 要求断开已消费的普通连线后，由符合当前槽契约的候选按原顺序补位。实测 Muse 首帧在当前画布格式下断开 A 后丢失已消费素材，B 的合法连线留存却一直没有装填。在旧画布格式下同一场景能补位。

- 使用当前目录中的 Muse 首帧方式，连入 A、B、C，核对初始只消费 A。断开 A 后显示 B，断开 B 后显示 C。保留其余连线及生成方式。
- 只补实际断开的自动占用。已有显式绑定、手动清空的槽、其他未填槽及不可用素材按原语义处理。保存后的图与提交读取同一组绑定。
- Seedance 的显式首尾帧方式在只剩一张图时保持方式及已用角色。缺另一张图时生成继续保持禁用。
