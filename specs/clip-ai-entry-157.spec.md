# 剪辑顶栏 AI 剪辑入口（#157）

基线为 `a156ac818f5115911688dcf4b853aebd8b953d98`。本次交付包括 [#157](https://github.com/omnimux-ai/omnimux-client/issues/157) 和 [#159](https://github.com/omnimux-ai/omnimux-client/issues/159) 阶段 2 评审的两条收尾项。素材库桥接由 [#158](https://github.com/omnimux-ai/omnimux-client/issues/158) 独立验收。

## 假设

- 两个剪辑入口共用原生顶栏和实时投影。基线的对话折叠或右栏全屏后，用户需要先恢复对话栏，再找输入框。已批准的前后对照演示把展开、聚焦和取当前剪辑上下文合到一个点击，并验证窄栏仍能操作导出与退出。
- 现有 [实时剪辑契约](../plugins/docs/contracts/clip-live-control.md) 以当前可见的编辑器、会话和工程为准。新入口从同一贡献者读取投影。Hub 复用原生 Composer 的附件槽位和聚焦逻辑，发送仍沿现有会话通路。
- 容器宽度决定入口文案是否可见。小于 560px 保留可聚焦的图标和完整无障碍名称。空间收紧时复用紧凑菜单，备份可从工程菜单进入。工程名称随剩余空间排布，保存态和主操作保留完整标签。

## 证伪方式

| 验收项 | 操作与判定 |
| --- | --- |
| AC-P3-01 对照 | 同一项目用批准的交互演示和实际浏览器入口核对前后布局、聚焦、播放头及选段。 |
| AC-P3-02 顶栏 | 画布与独立模式均检查 1120、760、460px。AI 入口紧贴导出左侧，窄栏为 30×30，导出、保存态和退出不挤压或换行。Welcome 无可触发入口，冲突期间不可请求上下文。 |
| AC-P3-03 展开与聚焦 | 从折叠态和原生右栏全屏点击，确认同一剪辑窗口保留且主 Composer 获得焦点。对照实时投影核实工程、两个版本字段、播放头、时长及至多三个选段，画布另核绑定。 |
| AC-P3-04 草稿与身份 | 先写多行草稿，移动播放头、改选段或版本后连点两次。只更新同一枚芯片，草稿逐字相同且发送次数为零。关闭再打开。另核隐藏 Composer、迟到挂载、切会话及编辑权释放。 |
| AC-P3-05 样式 | 在亮暗主题、简体中文和英文下检查实际按钮名称、聚焦描边和芯片。状态变化直接显示在对应位置。 |
| AC-P3-06 边界 | 通过插件边界检查。相对基线的桌面壳差异为零。WorkBench 与 Composer 由 Hub 托管，剪辑投影由 Clip 提供。 |
| AC-P3-07 工具回归 | 工具清单将运行时范围和窗口检查描述为实时工具行为。注册表内用 `ToolRuntime.execute` 运行合法 `clip_get`，并验证缺 `revisionEpoch` 的输出返回 `INVALID_TOOL_OUTPUT`。 |
