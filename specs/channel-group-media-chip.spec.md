# 渠道行显示模型分组支持的素材类型与数量

## 背景

画布素材节点的模型级联菜单里，渠道行目前只显示价格与计费芯片。用户希望在渠道标签处直接看到该分组支持的素材类型与数量，例如 `≤30 图`、`≤10 视频`、`≤10 音频`，样式参考第二张图的芯片。

## 目标

- 在 `ModelCascadeMenu` 的 `ChannelRow` 芯片行追加素材能力芯片：`≤N 图` / `≤N 视频` / `≤N 音频`。
- 数据来源优先级：
  1. `group.effectiveOperations`（网关分组变体的 `inputs[].max`，分组专属）；
  2. 回落到模型契约 `operations[].inputs[].max`（当前快照无分组变体时）；
  3. 再用 `group.constraints.inputs[type].max` 收口（`max: 0` 隐藏该类型）。
- 同一操作内同类型多个槽位求和，多个变体取最大；只显示 `max > 0` 的类型，顺序为图、视频、音频。
- 图片 / 视频 / 音频 / 文本节点共用同一渠道列，改一处全部生效；没有媒体输入的分组不显示芯片。

## 非目标

- 不修改网关分组数据、价格、计费、渠道选择与路由逻辑。
- 不改变模型级联菜单的列结构、宽度或选中行为。

## 验收

1. Seedance 2.5 的 480p / 720p 渠道行显示 `≤30 图`、`≤10 视频`、`≤10 音频`（与当前模型契约一致）。
2. 分组存在更窄的 `effectiveOperations` 时，按分组值显示（例如 `≤2 图`），不被模型级最大值覆盖。
3. `group.constraints.inputs.image.max = 0` 时对应芯片消失。
4. 纯文本模型、无媒体输入的渠道不显示芯片。
5. `channelGroups.test.mjs` 覆盖能力解析纯函数；`modelCascadeMenu.test.mjs` 保持通过；受影响构建通过。

## 旧标准变更

无。仅新增能力与断言。
